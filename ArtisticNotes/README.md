# ArtisticNotes — минимальный рабочий прототип

Мобильное приложение для учёта и систематизации аудио- и видеоконтента.
Соответствует требованиям курсового проекта (Kotlin + Room + Jetpack Compose).

## Что умеет

- Добавление аудио/видео записей
- Редактирование и удаление
- Поиск по названию и описанию
- Фильтрация по типу (Аудио/Видео) и категории
- Выбор файла через системный диалог (Storage Access Framework)
- Локальное хранение в Room (SQLite)

## Как запустить

### 1. Установи Android Studio
Скачай с официального сайта: https://developer.android.com/studio

### 2. Открой проект
1. Запусти Android Studio
2. **File → Open**
3. Выбери папку `ArtisticNotes`
4. Дождись синхронизации Gradle (первый раз может занять 2–5 минут)

### 3. Запусти на эмуляторе или телефоне

**Эмулятор:**
1. Tools → Device Manager → Create Device
2. Выбери любой телефон (например Pixel 6)
3. Скачай системный образ (API 34 рекомендуется)
4. Нажми зелёный треугольник ▶ Run

**Реальный телефон:**
1. Включи режим разработчика (7 раз нажми на «Номер сборки» в настройках)
2. Включи «Отладка по USB»
3. Подключи телефон кабелем
4. Нажми ▶ Run

### Возможные проблемы

- **Gradle sync failed** — проверь интернет, Android Studio скачивает зависимости
- **SDK not found** — Tools → SDK Manager → установи Android 14 (API 34)
- **KSP error** — File → Invalidate Caches → Restart

```
├── data/

│   ├── AppDatabase.kt    — база данных
│   └── MediaRepository.kt

│   ├── EditScreen.kt     — добавление / редактирование
│   ├── DetailScreen.kt   — карточка записи
│   └── MediaViewModel.kt
├── MainActivity.kt
└── ArtisticNotesApp.kt
```
